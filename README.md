# Esercizio: La bilancia di Babbo Natale
Nome repo: `js-la-bilancia-di-babbo-natale`

## Consegna
Dato un array contenente il peso degli ultimi giocattoli prodotti (fornito da noi - vedete sotto), il programma chiede all'utente l'operazione da svolgere, con una scelta tra:
* Peso medio: per calcolare il peso medio di tutti i giocattoli
* Peso massimo: per restituire il peso del giocattolo piu' pesante
* Peso minimo: per restituire il peso del giocattolo piu' leggero
* Numero di giocattoli: per restituire quanti giocattoli abbiamo pesato

Trovate in allegato due array da utilizzare. Il secondo array è piu' complicato, va usato solo come bonus

* `let pesiBase = [2, 5, 1, 1, 7, 3, 12, 6, 9, 3];`
* `let pesiBonus = [2, "5", 1, 1, "7", null, 12, 6, 9, 3];`
