## Assignment

You are given an array containing the weights of the latest toys produced at Santa's workshop.

The program must ask the user which operation they want to perform, allowing them to choose from the following options.

- **Average Weight:** calculate the average weight of all the toys.
- **Maximum Weight:** return the weight of the heaviest toy.
- **Minimum Weight:** return the weight of the lightest toy.
- **Number of Toys:** return the total number of toys weighed.

Two arrays are provided for this exercise.

**Base Array**

Use this array to complete the main assignment.

**Bonus Array**

A second, more challenging array is also provided. Use it only for the optional bonus challenge.

The bonus array contains values with different data types, including strings and `null`, making the calculations more challenging.

#### Bonus challenge

Try to complete the exercise again using `pesiBonus` instead of `pesiBase`.

Pay attention to the different data types in the array and consider how they affect the calculations.
